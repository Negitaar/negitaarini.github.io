SQL Revenue Analysis with the Sakila Database

Analyzed rental, customer, film, category, and payment data from the Sakila database to identify top-performing film categories, high-value customers, and revenue patterns for a video rental business.

SQL MySQL Python pandas SQLAlchemy Jupyter Notebooks Docker
More details

Problem

A video rental store manager needs to understand which film categories generate the most revenue and rental activity, as well as which customers contribute the most value. This analysis uses SQL to turn transactional rental and payment data into business insights that can support inventory, marketing, and customer engagement decisions.

Approach

Connected to a Dockerized MySQL Sakila database from a Jupyter Notebook using SQLAlchemy. Wrote SQL queries using joins, aggregation, HAVING clauses, common table expressions, and window functions to analyze revenue, rentals, category performance, and customer activity. Validated results with row-count checks, grouped summaries, and sanity checks.

Results & Impact

Produced a manager-style report ranking film categories by total revenue, total rentals, average revenue per rental, percent of total revenue, and revenue rank. The project demonstrates the ability to translate relational database tables into actionable business insights for operations and marketing decisions.

AWS Cloud Data Pipeline & Complaint Resolution Prediction

Built an end-to-end cloud-based data pipeline on AWS to analyze NYC 311 service request data and predict complaint resolution speed. Leveraged S3 for data storage, Athena for SQL-based querying, and SageMaker for machine learning, enabling scalable data processing and model development in a cloud environment.

AWS S3 AWS Athena AWS SageMaker SQL Python pandas scikit-learn Jupyter Notebooks
More details

Problem

Large-scale public service datasets, such as NYC 311 complaints, are difficult to analyze using local tools due to their size and complexity. There was a need for a scalable cloud-based workflow to store, query, and model the data efficiently, while also generating insights into factors influencing complaint resolution times.

Approach

Designed a structured data pipeline by uploading raw datasets to AWS S3 and organizing them into logical prefixes for reproducibility. Created external tables in Athena to query the data using SQL and engineered features for modeling. Generated a modeling dataset and exported it back to S3, then loaded it into SageMaker for machine learning. Built and evaluated a classification model to predict whether complaints would be resolved within three days, and compared local sklearn workflows with SageMaker built-in algorithms.

Results & Impact

Successfully implemented a scalable cloud workflow that integrates data engineering, SQL analytics, and machine learning. The model provides a baseline prediction of complaint resolution speed, demonstrating the ability to derive actionable insights from large public datasets. This project highlights proficiency in building reproducible cloud-based data pipelines and applying machine learning in a real-world context.
